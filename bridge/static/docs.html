Lumia Camera API

Keep Lumia Agent open on the Lumia. Use this page from another phone, tablet or computer.

Click Authorize and paste your agent_token. The token is kept only for this page session.

Try GET /v1/status. For a photo: POST /v1/preview or /v1/captures, poll GET /v1/jobs/{id}, then download the returned image. Crop an existing original with POST /v1/images/{id}/crop.
